# PIERS unified env — single conda env for BOTH paths:
#   (A) Effective-OmniSAM UDA (Cityscapes -> DensePASS/WildPASS)
#   (B) Grounded text branch (HF Grounding-DINO + vendored SAM2 predictor)
#
# Design decisions (RTX 6000D, cc 12.0 Blackwell sm_120, CUDA 12.8):
# - torch 2.8.0+cu128 / torchvision 0.23.0+cu128: first torch line with
#   official Blackwell sm_120 wheels. cu121 builds CANNOT run on this card.
# - transformers pinned to 4.57.6 (verified 2026-10-29 on CPU):
#   transformers 5.x renames/removes GroundingDino API; keep <5.
#   omni side does NOT import transformers, so no conflict.
# - sam2 is NOT pip-installed: we import third_party/*/sam(2) directly
#   (pure-Python path, SAM2_BUILD_CUDA=0 semantics). CUDA ext
#   (connected_components.cu -> sam2._C) is compiled in-place on GPU host
#   only if needed; both misc.py fall back gracefully when _C is absent.
# - Install with:  pip install -r requirements.txt
#   (extra-index-url brings the cu128 torch wheels; everything else from PyPI)
# - Env location on AutoDL MUST be on the data disk, e.g.
#   conda create -p /root/autodl-tmp/envs/piers python=3.12 -y
#   NOT /root/miniconda3/envs/ (root overlay / is only 30G).
