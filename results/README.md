# Result ledgers

Compact, versionable records of every number reported in the paper. These
files are the *outputs*; `experiments/` holds the *code* that produced them.

Nothing here is a raw prediction dump — per-image predictions and caches are
large and are regenerated by rerunning the pipeline. What is stored is the
per-image metric ledgers, the aggregate reports, the protocol records and the
environment/fingerprint evidence needed to trust the numbers.

| Directory | Run | What it holds |
|---|---|---|
| `I1_densepass/` | `I1-densepass-20261107_121457` | Innovation-1 main experiment on DensePASS100 |
| `I1_collab/` | `I1-collab-20261106_213607` | Collaboration (text↔semantic) experiments, incl. the gated variants |
| `E0/` | `E0-effective-start` | Baseline OmniSAM-S evaluation |
| `I2_I3/` | I2 / I3 run records | Innovation-2 and Innovation-3 run records |

## I1_densepass — the main ledger

| File | Contents |
|---|---|
| `FINAL_STATUS.json` | Final state of the run |
| `protocol.json` | **The protocol of record**: splits, seeds, optimizer, budgets, checkpoint, GT mapping, and the explicit caveats (development set, no training-gain claim) |
| `final_method.json` | The frozen method description |
| `final_frozen_report.json` / `final_frozen_per_image.json` | Headline frozen-inference results, aggregate + per image |
| `core_report.json` / `core_per_image.json` | Core comparison results |
| `bounded_report.json` / `bounded_per_image.json` | Bounded-budget comparison results |
| `train160.json` / `val100.json` | The exact train/val manifests used (with `${PIERS_*}` placeholders) |
| `source_fingerprints.json` | SHA256 of every source file that produced the numbers |
| `source_snapshot/` | Those source files, byte-for-byte |
| `source_snapshot.tar.gz` | The same, as archived on the experiment machine |
| `environment_pip_freeze.txt` | Full `pip freeze` of the experiment environment |
| `environment_runtime.txt` | Python / torch / CUDA / GPU |
| `weights_checksums.txt` | Weight checksums and the dataset layout |
| `cooperation_checks.json`, `real_text_parity.json`, `text_error_diagnosis.json`, `smoke_semantic_comparison*.json` | Specific correctness checks |
| `performance.json`, `performance_v1.json`, `profile_wait.json` | Timing measurements |

### Verify the code matches the numbers

```bash
python scripts/piers/verify_result_fingerprints.py
```

This hashes `source_snapshot/` against `source_fingerprints.json` and must
report `14/14 files match`. If it does, the code in this repository is
provably the code that produced these numbers.

## Reading order

1. `protocol.json` — what was run, under what protocol, what is and is not claimed
2. `FINAL_STATUS.json` — the final state
3. `final_frozen_report.json` — the headline numbers
4. `*_per_image.json` — per-image detail behind the aggregates
