## 目标与可行性判断

用户希望完整 I1/I2/I3 模型保留开放词汇分割能力，在相同设备、相同图像/分辨率、相同类别列表和计时范围下，真实端到端比原始 OmniSAM 更快，同时分割精度有提升。不要仅以 token 预算或某个模块耗时宣称达标。

这个目标尚未实现，也不能预先保证可实现。桌面 GPU 上语义核心约 4 秒，完整系统新增文本分支约 7–13 秒；Jetson 阶段记录中文本约占 89%。仅完成现有 30%–36% 的文本局部加速不够。需要先建立“语义核心＋文本分支＋融合＋输出”的可达延迟预算，找出能超过基线的具体组合。若严格保留当前全部计算后没有可达路径，请如实给出实测折中，不编造达标。

分别回答两个问题：
1. 论文原始任务对比：原始 OmniSAM 与完整模型在同一图像和计分协议下的精度/延迟。明确原始模型没有新类别和文本功能，不能把它包装成同功能文本基线。
2. 相同文本功能对比：原始 OmniSAM＋同样的 DINO/SAM2 文本资源，与优化后完整模型，保持类别、输出要求一致。这用于证明系统工程收益，但不能用它替换第 1 个用户目标。

- 保持完整文本/I1/I3、只开关 I2：13.45694→13.38210 s，均值仅约0.56%下降，中位数近乎相同；设备峰值9456→9522 MiB。Dense100 mIoU 60.92178301→60.85548850。不能宣称没有 I2 系统一定明显更慢、显存更多。
- Jetson 仅核验过相同图片顺序的前63次预热后请求，300次完整完成情况未在本次核实：原始 e2e4.29759 s，完整67.16242 s；完整文本59.52166 s；语义core4.47061 s，fusion2.76474 s；Memory区间1044.07→707.89 ms。先找真实完整记录，不把阶段记录说成最终300次结果。
- Jetson 已有低峰值窗口合并、单全景 SAM 裁剪缓存、语义 encoder 缓存的记录，先查实际运行版本；不要重复宣称首次实现。encoder_engine:null，不能因磁盘存在引擎就说正式使用 TensorRT。

## 工作顺序

1. **先建立可达预算与剖析。** 记录当前原始/full/full_cached 的逐阶段耗时、DINO调用数、SAM编码/解码数、语义forward数、传输和融合耗时；分开冷加载、首请求、稳定请求。每个新图都真正计算，禁止使用已保存预测代替推理。
2. **先验证现有缓存。** 全量四个口径检查预测 hash 和混淆矩阵；遇不一致定位到候选、浮点变化或缓存污染。桌面与 Jetson 分别测试，不互相换算。记录命中率、常驻显存和淘汰策略；不同图片不能误复用结果。
3. **文本侧是主要瓶颈。** 研究同 FoV 多类别提示/批处理、图像编码复用、批量框解码、避免进程往返和重复前处理。合并提示会改变预测，必须作为新方法重测；严格校验短语/token 到原始类别的归属。保留任意类别输入，不能只为13类写死。
4. **同时评估语义核心。** 核对正反向共享 encoder 是否已有；减少峰值临时 logits、CPU/GPU复制和融合开销。减少窗口/分辨率、替换模型、蒸馏、量化均视为新配置，完整重测。蒸馏训练优先使用源域数据，目标域监督另列域适应实验。
5. **I2 若要降低常驻内存，必须改存储。** 只读出索引不会释放历史张量。若压缩写入存储，处理位置编码、类别配额、时序/伪标签、历史窗口和接缝恢复，记录实际存储字节、临时峰值和完整耗时。
6. **编译/精度后端公平。** FP16、BF16、TensorRT等先验证支持性和数值误差；同样适用于原始基线的优化也要给基线使用并另报公平表。不能只优化完整模型后把收益全部归算法。
7. 策略在源域/开发集固定后再做正式目标数据评测，不用 Wild/Syn 测试 GT 来挑超参数。

## 实验设计与验收

至少包含：original、冻结full-v3、full_cached、优化后的full；同功能文本基线另列；必要时列同后端优化后的original。每个候选有配置、源码hash、权重hash、依赖和原始记录。

- **精度**：完整 Dense100、Wild500、Syn1690 原生22及独立映射13，报告总混淆矩阵、逐类IoU、mIoU/mAcc/PixelAcc/FWIoU/mDice。输出完全相同可报告全量 hash 相等；输出有变化必须重新评分。图像配对 bootstrap CI；不能平均单图 mIoU 充当数据集 mIoU。
- **延迟**：同设备、功耗模式、温度条件、固定图片顺序、尺寸、类别列表和最终输出。单任务独占GPU；交错 ABBA 或平衡顺序；充分预热，建议30张固定分层样本×至少3轮。记录每次请求，不只给均值。含模型计算、必要IPC、融合和最终输出；冷加载单列；网络/UI传输另列，不能混作算法时延。
- **效率指标**：均值/中位数/P95，吞吐单独测；进程 allocated/reserved 与整设备 used 显存分别记录；Jetson另报系统共享内存、功耗/能耗、温度及是否降频。不要把桌面GPU峰值当Jetson内存。
- **消融**：在相同完整功能下分别开关缓存、I2、批查询/批解码、合并实现，定位收益；保持原始/full主表可对照。
- **目标**：优化full真实e2e低于公平original，且相对original精度提升、保留开放词汇能力。相对冻结full，先追求预测等价；若近似优化，事先说明允许的精度损失与最终选型依据，不能事后挑最好测试集。
