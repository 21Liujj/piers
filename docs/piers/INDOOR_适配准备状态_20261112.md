## 2. 关键发现：底座原生支持 SPAN8

`third_party/effective_omnisam` 原生已支持室内，无需自造 loader：

- `DATASET_NAME2CLASSES["Stanford2D3D"]` = SPAN8 8 类，顺序一致
- `dataset/Stanford360Span8.py` 读 `images/` + `labels_trainid/` + `lists/*.txt`
- trainId 语义正是 0~7 + 255=ignore，与我们的转换结果**逐像素一致**

因此 `indoor_make_layout.py` 用 symlink 把 `SPAN8_PREP` 物化成上游目录结构
（`/root/autodl-tmp/data_extra/Stanford2d3d_Seg`），**上游 loader 原样复用**，
适配面最小化，冻结的室外路径零改动。

实测 loader 输出：
```
fit images 832
img (18, 3, 512, 512)   lbl (18, 512, 512)
label uniq [0,1,2,3,5,6,7,255]
```
18 = 9 starts × 2 passes，与几何设计一致。

## 3. 几何（方案 B：1024×512）

用户选定 B 方案，理由是省 4 倍算力且 GT 原生分辨率即 512 高。

| 项 | 室外（冻结） | 室内（新） |
|---|---|---|
| canonical | 2048×400 → 4096×1024（2× 放大） | 1024×512（原生，无放大） |
| window | 1024×1024 | 512×512 |
| stride | 384 | 64 |
| starts | 9 | 9 |
| passes | 2 | 2 |
| base forwards | 18 | **18（一致）** |
| I3 额外 | +2 | **+2（一致）** |
| 单窗像素 | 1M | **0.26M（1/4）** |

文件：`indoor_geometry.py`（含 `check_indoor_geometry()` 自检）

## 4. I3 室内独立版

**冻结的室外 `runs/I3-seam-20261107/seam_core.py` 与 `seam_cuda.py` 一个字未改。**

新建 `indoor_seam_i3.py`，把室外所有硬编码街景常数换成几何参数：

| 室外硬编码 | 室内参数化 |
|---|---|
| `seam_mask(H=400, W=2048)` | `seam_mask(H=512, W=1024)`，band 按比例 64 |
| `base_coverage()` 4096/384 | `i3_base_coverage()` 由 starts 推导 |
| 候选 `[1664..1920]` | `i3_candidate_starts()` → `[512,640,768,896,1024]` |

**六个核心公式逐字复刻室外注册版本**：
`centrality` / `support` / `semantic_risk` / `choose` / `fuse` / `fuse_cuda`。

自检结果：
```json
{"B0_identity": true, "plan_b2": [768, 896],
 "coverage_min": 2.0, "coverage_max": 16.0, "seam_band_px": 64}
```
`B0_identity=true` 表示 B=0 严格退化为 base 输出，与室外契约一致。

## 5. Checkpoint 加载：原 ckpt 上微调

**回答「是不是只能在原 ckpt 上微调」：是的，而且路径已验证。**

`utils/checkpoint_adapt.py::smart_load_checkpoint` 用 `strict=False`：

```
ckpt decoder.linear_pred.weight shape = [13, 256, 1, 1]
new head = 8 classes
→ 形状不匹配 → 自动跳过，不报错
```

即：**13 类分类层不加载，8 类头随机初始化后完整训练**；
其余 1806 个张量（含 192 个 LoRA 张量、918 个 memory 张量）正常加载。

audit 输出（CPU 实测）：
```json
{"total_tensors": 1806, "lora_tensors": 192, "decoder_tensors": 14,
 "memory_tensors": 918, "head_shape_13cls": [13,256,1,1]}
```

### 可训练参数划分

| 部分 | 状态 |
|---|---|
| encoder LoRA（`linear_a_`/`linear_b_`，192 张量） | 训练，lr 1e-5 |
| decoder SegFormer 头（含新 8 类 `linear_pred`） | 训练，lr 1e-4 |
| encoder 基础权重 | 冻结 |
| memory bank / DINO / text 分支 | 冻结 |
| 室外 I1/I2/I3 源码 | 不动 |

调度：head warmup 200 步（只训头）→ 1200 步 joint，cosine 衰减，wd 0.01，clip 1.0，grad accum 4。

## 6. 对比矩阵

`indoor_experiment_matrix.py` → `INDOOR_EXPERIMENT_MATRIX.json`（已生成到远端）

| Arm | 描述 | 头 | 适配 | memory | forwards | I3 | text |
|---|---|---|---|---|---|---|---|
| Z0 | 原始 OmniSAM，冻结街景 13 头 | street13 | 否 | dense | 18 | 0 | 否 |
| Z1 | 原始 OmniSAM + 完整 I1/I2/I3 | street13 | 否 | i2 | 20 | 2 | 是 |
| A0 | 适配后，dense | span8 | 是 | dense | 18 | 0 | 否 |
| A1_B0 | 适配后 + I2，18 forward | span8 | 是 | i2 | 18 | 0 | 是 |
| A1_B1 | 适配后 + I2，19 forward | span8 | 是 | i2 | 19 | 1 | 是 |
| A1_B2 | 适配后 + I2，20 forward | span8 | 是 | i2 | 20 | 2 | 是 |

核心对比：
- `Z0 → A0`：**室内适配收益**（原始 OmniSAM vs 我们的完整模型）← 用户要求的对比
- `Z1 → A1_B2`：**完整系统收益**（I1/I2/I3 两侧都有）
- `A1_B0 → A1_B2`：**I3 总效应**
- `A0 → A1_B0`：I2 memory 在适配模型上的效应

Z 组用街景 13 头 + `map13_to_span8` LUT（beam/board/bookcase/clutter/column 无对应 → 结构零召回，
这正是室外 I1 同样的诚实披露口径）。

**GT 只由 scorer 读，模型路径零泄漏。** `indoor_scorer.py` 提供 mIoU / mAcc / 逐类 IoU。
