# 全景图像分割系统：交付与验证（2026-11-11）

实现位于 `apps/panorama_web/`，启动方法见该目录 README。网页只在本机监听；GPU服务只在服务器回环地址监听，通过SSH通信。产品标题为“全景图像分割系统”。

## 已实现

- 全景图上传、街景/室内选择；不输入文本时分别使用可扩展的21类/8类默认类别表；文本输入支持任意英文类别/短语及收录的常见中文类别。
- 街景调用冻结完整 I1/I2/I3 与开放词汇竞争；室内是通用 Grounding DINO＋SAM2 零样本路线，不套用街景13类头与源域校准器，不声称室内LoRA已完成。
- 语义图、实例图、原图/结果滑动对照、透明度、缩放拖动、类别/实例单独突出显示；PNG/JSON/ZIP导出、任务历史、进度、取消及失败详情。
- 按共同可见区域关联跨FoV实例，保存16位全图实例ID，并保留接缝两段框。实例数量为模型估计，尚未测实例AP；无重叠证据的碎片不强行合并。地面/天空等stuff保留语义区域输出。
- 论文四种口径的历史真实指标、逐类IoU和小样本效率展示，支持指标切换与原始表导出。无GT的上传任务不报准确率；有GT时在本机计算单图指标并更新下载包。
- 模型按需加载、空闲卸载、共享GPU锁和多来源占用检测；不停止其他实验进程。网页推理使用独立的冻结源码，避免与效率开发代码混用。

## 已通过的验证

1. 18项CPU契约测试：开放词汇/空文本、接缝和跨视窗去重、相邻实例不误合并、stuff不误计为对象、类别ID/二值指标及无效GT拒绝、评分指标写入下载包、API/导出契约、NVML列表为空时的实验避让。
2. 真实GPU街景文本请求“汽车”：完整模型输出类别掩码、4个估计实例，包含跨视窗和接缝对象。该数量是模型输出，不是人工标注的实例计数。
3. 真实GPU街景空文本请求：21类完整推理成功，包含源头13类以外的输出；审计确认20次语义forward、Memory Attention最大1024 token。
4. 真实GPU室内空文本请求：通用8类路线完成，生成多类掩码；未读GT、未训练，不提供室内mIoU结论。
5. 独立推理源码926个文件逐一校验到 `82d20b5b4ba24c42666dd8fee548d5c8618505c8`；四套历史整数账本CPU回放通过。切换后再次真实运行21类请求，与切换前类别图逐像素一致（不同像素0）。
6. 浏览器实测上传、实例突出显示、滑动对照、实验表与ZIP下载。实际ZIP包含类别ID、16位实例ID、透明掩码、叠加图及运行JSON。显示修订保留了三个验收请求原有类别PNG的SHA256。

第一次集成测试暴露了SSH通道读取HTTP/1.0关闭响应时的截断，已改为带明确长度的HTTP/1.1响应并通过后续真实请求验证。失败任务保留在本机历史中。

## 适用范围

- 这些交互请求的时间包含排队、首次加载、网络及显示输出，不作为论文的隔离效率实验。完整系统加速尚未达标，候选缓存默认关闭。
- 室内LoRA、复杂关系文本的可靠执行、实例AP、完整数据集对网页服务的重新评测尚未完成。常见中文类别可用；未收录中文会明确提示使用英文。
- 默认街景21类交互任务与论文13/8/22类评测口径不同，不能将历史mIoU标成当前上传图片的精度。
- 并行效率实验使用独立checkout；正式测速前应释放网页GPU模型并采用同一GPU互斥锁。新服务器复现仍需按许可自行准备数据和仓库说明中的权重/依赖。

私有SSH连接、用户图片、运行数据库、验收样图和原始任务输出保存在用户本机/服务器运行目录，不随源码发布。
